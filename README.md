# Homebrew tap for Claudometer

[Claudometer](https://github.com/Faithful-developer/claudometer) shows your Claude plan usage limits in the macOS menu bar and as a desktop widget.

```sh
brew install --cask faithful-developer/tap/claudometer
```

Claudometer updates itself (Settings › About, or **Install Update** in the menu). `brew upgrade --cask claudometer` works too.

The cask is bumped automatically by Claudometer's release script.
